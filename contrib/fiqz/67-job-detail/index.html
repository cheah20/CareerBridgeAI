Role Description

Zenith Global Solutions Sdn Bhd is seeking a motivated Junior Mobile App Developer to build and maintain cross-platform mobile applications using Flutter and Dart. You will collaborate closely with backend FastAPI engineers and product designers to deliver responsive, reliable customer experiences.

Key Responsibilities

  • Develop modular mobile screens and reusable UI widgets in Flutter and Dart.
  • Integrate RESTful API endpoints and manage local offline caching with SQLite/Firebase.
  • Write clean, version-controlled code using Git and participate in sprint reviews.
  • Assist senior engineers with automated build checks and app store releases.

Minimum Qualifications

  • Bachelor's Degree or Diploma in Computer Science, Software Engineering, or related field.
  • Hands-on project or internship experience building Flutter mobile applications.
  • Familiarity with REST APIs, JSON parsing, and Git workflows.
