# Starter page

Copy this whole folder to begin a new page. It already has the CareerBridge colours, font, menu, cards, table, buttons and status labels.

| File | What to do with it |
|---|---|
| `index.html` | Your page. Replace the example content inside `<main>`. |
| `style.css` | Shared look. Do not change the top part; add your own styles at the bottom. |
| `script.js` | Small examples (tabs, a button that shows a message). Add your own code at the bottom. |
| `NOTES.md` | Fill in before you hand in. |

Double-click `index.html` to open it in Chrome. After you save a change, press F5 in Chrome to see it.
