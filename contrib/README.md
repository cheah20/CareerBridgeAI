# Teammate submissions

Hand in your work here. Nothing in this folder is part of the running website.
The owner reviews each task and later turns good pages into the real app (Flutter).

| Teammate | Folder | Pages |
|---|---|---|
| Ong | [`ong/`](ong/) | Admin pages |
| Fiqz | [`fiqz/`](fiqz/) | Recruiter pages |
| Fathiyah | [`fathiyah/`](fathiyah/) | Job Seeker pages |

## How a task folder looks

```
contrib/
  _starter/                 <- copy this to begin every page (HTML, CSS, JS ready)
  ong/
    12-admin-dashboard/     <- task number + short name
      index.html
      style.css
      script.js
      NOTES.md              <- what you made and anything unfinished
```

You can use plain **HTML, CSS and JavaScript**. No Flutter needed.
Start from [`_starter/`](_starter/) so every page has the same colours, fonts and buttons.

How to upload, step by step: [docs/CONTRIBUTING.md](../docs/CONTRIBUTING.md)
