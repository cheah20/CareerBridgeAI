7 · Key findings

  1. Public-dataset accuracy did not predict real-CV accuracy.
  2. v5 had learned the datasets' text format; normalising text fixed it.
  3. Synthetic resumes did not make a measurable difference on real CVs.
  4. Who writes the test labels matters: shared conventions inflated one result.

8 · Next steps

  • v2 stays deployed; work returns to the application.
  • No lawful public source of real MY / SG resumes was found (searched universities, job sites, open datasets).
  • Admin, logistics and oil & gas roles cannot be validated yet: no real CVs, no public category.
  • Re-test when consented real resumes are available; synthetic batch on hold.

  • Public data: ResumeAtlas (MIT) + Kaggle Resume Dataset (CC0), 14,081 resumes, 45 categories; split 11,264 / 2,817, seed 42.
