# Login and sign-up

Everything about accounts.

| File | What it is |
|---|---|
| `login_page.dart` | The login page |
| `signup_page.dart` | The sign-up page |
| `session.dart` | Remembers who is logged in and their role |
| `auth_backend.dart` | Talks to Supabase to log in and out |
| `auth_widgets.dart` | Shared boxes and buttons for these pages |
| `loading_page.dart` | Shown while checking the login |
