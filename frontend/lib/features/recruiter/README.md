# Recruiter pages

What a company recruiter sees after logging in. Built from Fiqz's HTML pages in `contrib/fiqz/`, with sample data for now.

| File | What it is |
|---|---|
| `recruiter_overview_page.dart` | The recruiter's home page |
| `company_profile_page.dart` | Company details, verification status and edit form |
| `job_posts_page.dart` | The company's jobs: edit, close, reopen, delete drafts |
| `job_form_page.dart` | Post a job or edit one |
| `applicants_page.dart` | Applicants for a job, highest match first, with filters |
| `applicant_detail_page.dart` | One applicant: resume, AI match and status history |
| `applicant_manage_page.dart` | Change an applicant's status or set an interview |
| `recruiter_support_page.dart` | Help and bug report form, with earlier reports |
| `recruiter_sample.dart` | Shared sample data for these pages |
| `recruiter_parts.dart` | Small table and form pieces used by these pages |
