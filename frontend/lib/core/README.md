# Shared building blocks

Pieces used on many pages, so every page looks the same.

| File | What it is |
|---|---|
| `widgets/glass.dart` | Cards, the page frame and small labels |
| `widgets/page_parts.dart` | Page titles, number strips, card headers |
| `widgets/list_parts.dart` | Rows in lists, progress bars |
| `layout/breakpoints.dart` | When the layout switches between wide and narrow screens |
