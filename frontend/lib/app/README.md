# Look and page list

| File | What it is |
|---|---|
| `theme/glass_tokens.dart` | **All colours** in one place (light page `paper` is the default) |
| `theme/app_theme.dart` | Fonts, buttons and boxes built from those colours |
| `router.dart` | The list of pages and their web addresses, and who may open them |
| `app.dart` | Starts the website |
| `config.dart` | Reads the settings file (`config/dev.json`) |

To change a colour everywhere, change it in `glass_tokens.dart`.
